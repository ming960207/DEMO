# Web应用开发指南

## 项目概述

本文档为Web应用项目提供全面的开发指导和最佳实践。

## 技术架构

### 前端架构
- **框架**: React 18 + TypeScript
- **构建工具**: Vite (快速开发和优化构建)
- **路由**: React Router v6 客户端路由
- **状态管理**: React Query (服务器状态) + React Hooks (本地状态)
- **样式**: Tailwind CSS 实用优先的样式框架
- **测试**: Vitest + React Testing Library

### 后端架构
- **运行时**: Node.js + Express.js
- **语言**: TypeScript (类型安全)
- **数据库**: MongoDB + Mongoose ODM
- **认证**: JWT令牌认证
- **安全**: Helmet, CORS, 速率限制
- **测试**: Vitest + Supertest

## 开发环境设置

### 1. 环境要求
- Node.js (v18.0.0 或更高版本)
- npm (v9.0.0 或更高版本)
- Git
- MongoDB (本地或云端)

### 2. 项目初始化

```bash
# 克隆项目
git clone <仓库地址>
cd web-application-project

# 安装所有依赖
npm run install:all

# 配置环境变量
cp .env.example .env
# 编辑 .env 文件配置您的本地环境

# 启动开发服务器
npm run dev
```

### 3. 可用脚本命令

#### 根目录脚本
- `npm run dev` - 同时启动前端和后端开发服务器
- `npm run build` - 构建生产版本
- `npm run test` - 运行所有测试
- `npm run lint` - 代码检查
- `npm run format` - 代码格式化
- `npm run install:all` - 安装所有包的依赖
- `npm run clean` - 清理所有node_modules和构建目录

#### 前端专用脚本
- `npm run dev:frontend` - 启动前端开发服务器 (http://localhost:3000)
- `npm run build:frontend` - 构建前端生产版本
- `npm run test:frontend` - 运行前端测试

#### 后端专用脚本
- `npm run dev:backend` - 启动后端开发服务器 (http://localhost:3001)
- `npm run build:backend` - 构建后端生产版本
- `npm run test:backend` - 运行后端测试

## 开发工作流程

### 1. 功能开发流程
1. **创建功能分支**: `git checkout -b feature/功能名称`
2. **开发功能**: 编写代码和测试
3. **代码检查**: `npm run lint` 和 `npm test`
4. **提交代码**: 使用规范的提交信息
5. **创建Pull Request**: 详细描述变更内容

### 2. 代码规范

#### TypeScript指南
- 使用严格的TypeScript配置
- 为所有数据结构定义接口
- 使用适当的类型注解
- 避免使用 `any` 类型

#### React开发指南
- 使用函数组件和Hooks
- 实现适当的错误边界
- 使用React.memo进行性能优化
- 遵循单一职责原则

#### API开发指南
- 遵循RESTful约定
- 实现适当的错误处理
- 使用一致的响应格式
- 包含适当的HTTP状态码

### 3. 测试策略

#### 前端测试
- 工具函数的单元测试
- 使用React Testing Library的组件测试
- 用户流程的集成测试
- 关键路径的端到端测试

#### 后端测试
- 业务逻辑的单元测试
- API端点的集成测试
- 数据库集成测试
- 安全性测试

## 项目结构详解

### 前端目录结构
```
frontend/src/
├── components/          # 可复用UI组件
│   ├── UI/             # 基础UI元素 (Button, Input等)
│   ├── Layout/         # 布局组件 (Header, Footer等)
│   └── Feature/        # 功能特定组件
├── pages/              # 页面组件
├── hooks/              # 自定义React钩子
├── utils/              # 工具函数
├── styles/             # 全局样式和CSS模块
└── assets/             # 静态资源
```

### 后端目录结构
```
backend/src/
├── controllers/        # 路由处理器
├── models/            # 数据库模型
├── routes/            # API路由定义
├── middleware/        # 自定义中间件
├── utils/             # 工具函数
└── config/            # 配置文件
```

## 故障排除

### 常见问题
1. **端口冲突**: 检查.env文件中的端口配置
2. **依赖问题**: 运行 `npm run clean` 然后重新安装
3. **TypeScript错误**: 检查tsconfig.json配置
4. **数据库连接**: 验证MongoDB连接字符串
