## 🌿 Git工作流规范

### 基本原则
- **主分支保护**: `main` 分支始终保持可部署状态
- **功能分支开发**: 所有新功能必须在独立分支开发
- **代码审查必须**: 任何代码合并到主分支前必须经过审查
- **自动化测试**: 所有提交必须通过自动化测试

### 分支命名规范
```
feature/功能名称        # 新功能开发
bugfix/问题描述         # Bug修复
hotfix/紧急修复         # 生产环境紧急修复
refactor/重构内容       # 代码重构
docs/文档更新          # 文档更新
test/测试相关          # 测试相关
chore/杂项任务         # 构建、配置等杂项
```

### 工作流程
1. **创建分支**: `git checkout -b feature/用户认证系统`
2. **开发功能**: 在分支上进行开发
3. **本地测试**: `npm test && npm run lint`
4. **提交代码**: 遵循提交规范
5. **推送分支**: `git push origin feature/用户认证系统`
6. **创建PR**: 详细描述变更内容
7. **代码审查**: 至少一人审查通过
8. **合并代码**: 使用 Squash and Merge
9. **删除分支**: 合并后删除功能分支

## 🔒 安全规范

### 数据安全
- **敏感信息**: 不得在代码中硬编码密码、密钥等
- **环境变量**: 使用环境变量管理配置
- **数据加密**: 敏感数据必须加密存储
- **传输安全**: 生产环境必须使用HTTPS

### 输入验证
```typescript
// ✅ 推荐：服务端验证
import { body, validationResult } from 'express-validator';

export const validateCreateUser = [
  body('email').isEmail().normalizeEmail(),
  body('password').isLength({ min: 8 }).matches(/^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/),
  body('name').trim().isLength({ min: 2, max: 50 }),
  
  (req: Request, res: Response, next: NextFunction) => {
    const errors = validationResult(req);
    if (!errors.isEmpty()) {
      return res.status(400).json({ errors: errors.array() });
    }
    next();
  }
];
```

### 权限控制
```typescript
// ✅ 推荐：中间件权限检查
export const requireAuth = (req: Request, res: Response, next: NextFunction) => {
  const token = req.headers.authorization?.replace('Bearer ', '');
  
  if (!token) {
    return res.status(401).json({ error: '未提供认证令牌' });
  }
  
  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET!);
    req.user = decoded;
    next();
  } catch (error) {
    return res.status(401).json({ error: '无效的认证令牌' });
  }
};
```
